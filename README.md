Portafolio Profesional — Angel Ortega

Sitio web de portafolio personal diseñado para presentar mis proyectos de Desarrollo de Software, Automatización con Inteligencia Artificial y Soporte Técnico TI.

🔗 Demo en vivo: https://aortegadevpa.github.io

✨ Características Principales

Interfaz Trilingüe Dinámica (ES / EN / PT): Cambio instantáneo de idioma en toda la interfaz, incluyendo secciones, formulario y detalles técnicos de cada proyecto.

Diseño Responsivo y Oscuro: Estética moderna con efectos glassmorphism, tipografía técnica (Inter + JetBrains Mono) y soporte optimizado para exportación a PDF / Impresión limpia.

Modales Interactivos de Proyectos: Desglose estructurado bajo el formato Problema → Solución Implementada → Arquitectura & Flujo Técnico → Stack Tecnológico.

Formulario de Contacto Funcional: Integrado con FormSubmit para recepción directa de mensajes en correo electrónico sin necesidad de servidor backend, con validación en tiempo real.

Utilidades Rápidas: Botones de copiado seguro al portapapeles para correo electrónico y tarjeta de contacto profesional.

🛠️ Tecnologías Utilizadas

Estructura & Estilos: HTML5 semántico, Tailwind CSS (CDN), CSS3 personalizado.

Interactividad: JavaScript Vanilla (ES6+), Intersection Observer API para animaciones al desplazarse.

Iconografía & Fuentes: Font Awesome 6, Google Fonts.

Servicios & Despliegue: FormSubmit (formularios estáticos), GitHub Pages.

📂 Estructura del Proyecto

├── index.html      # Aplicación web completa (estructura, estilos, traducciones y lógica)
└── README.md       # Documentación del repositorio
